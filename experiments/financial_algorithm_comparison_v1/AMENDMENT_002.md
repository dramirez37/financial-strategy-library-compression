# Financial algorithm comparison amendment 002

Recorded: 2026-08-27, after the annual parent replay failed and before any new
algorithm was dispatched or any comparison output was written.

The repaired wrapper verified the design lock and replayed the terminal source
evaluation. The annual resource child then recomputed all five annual decision
certificates but rejected them against the committed status. A separate
nonmutating parent `--check` reproduced the same drift. The licensed annual
panel SHA-256, parent configuration SHA-256, runner SHA-256, and design-lock
file hashes all match their committed values.

The discrepancy is fully explained by the string included in the decision
certificate. Reconstructing the 2020 certificate from the committed ranking
and selection rows gives the committed hash
`23615ce29b83cacb38d1919c7ef9c8922cc66edd1482689a0041cb14895e4bb9`
when the registered analytical design hash
`6c92ad2b12196f6e481fac5a4c3b3703591f4ec20861df44b75bee3618c51e88`
is used, and gives the replayed hash
`fdae8e09a1ffde70eb68ea4a212ae9e92f13e30bbe1e73df359781654f5bcca1`
when the later taxonomy lock hash is used. The post-outcome taxonomy migration
changed no ranking or selection, but the current parent runner passes that
new lock identity into the analytical decision hash. The frozen parent is not
rewritten or silently accepted.

The extension will instead import each frozen source library and historical
stepwise endpoint from the already audited, committed cross-audit membership
certificates. It rebuilds the exact strategy modules from the locked grammar
and recomputes only the source validation profiles from the licensed panel.
The resulting exact source frontier and module union must equal the committed
cross-audit frontier and closure certificates before any new algorithm runs.
The already committed audit-specific held-out opportunity sufficient statistic
is parsed only by the ex-post evaluator after all new optimization is complete.

A pre-lock reconstruction check used the licensed panels but did not dispatch
any new algorithm or evaluate a new comparison outcome. It recovered the 80-
strategy terminal source with its 25-strategy historical stepwise endpoint and
the 202-strategy annual source with its 100-strategy historical endpoint. Both
reconstructed source objects passed exact equality against their committed
frontier, closure, weight, and membership certificates. These sizes are
preexisting committed aggregate facts, not results of the new comparison.

The amendment also fixes the manual public-promotion gate before outcomes
exist. Promotion requires the local exact audit, validates the complete
registered comparison grid and separate held-out units, and permits only the
aggregate summary, audit/provenance status, and mechanically generated results
report to cross the licensed-data boundary.

This changes execution plumbing, not scientific content: source identifiers,
weights, profiles, frontier, closure, historical comparator, algorithms,
seeds, limits, tie rules, information boundary, and estimands are unchanged.
The annual parent replay failure remains recorded and must be disclosed; this
amendment does not claim that the parent `--check` passes.
