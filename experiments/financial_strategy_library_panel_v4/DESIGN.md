# Calibrated Closure-Activated Mechanism Experiment

## Decision and hypothesis

The primary hypothesis is directional and theory-derived: in the powered
positive regime, the mean realized productive value of the innovation-safe
oracle exceeds that of an equal-burden frontier-only comparator.

The two libraries have the same current operating frontier and the same
retention burden. The safe library alone retains the bridge capability needed
to run a registered research project. The descendant gain is chosen before
test-world simulation so that

`M = beta^d * rho^d * pi * G - kappa`

equals the regime's registered net bridge margin. The frontier-only project is
infeasible. The safe oracle researches exactly when `M > 0`.

## Market calibration without sign selection

Every complete proposal candidate path from every gate-passed v3 cell is used
to estimate three nuisance features: daily idiosyncratic strategy volatility,
lag-one dependence, and residual tail thickness. Cross-strategy date means are
removed inside each cell before calibration. These nuisance estimates determine
the proposal-noise law but never determine the sign of a v4 regime.

An independent null simulation fixes the learner's one-sided adoption
threshold. Test worlds use disjoint seeds. The primary powered margin is twice
that threshold, a prospective power design rather than a post-result choice.

## Four registered regimes

- **Adversarial:** negative one calibrated threshold; both oracles abstain.
- **Null:** zero bridge margin; both oracles abstain and learner size is tested.
- **Low-dose positive:** the existing 25 bp economic hurdle.
- **Powered positive:** twice the calibrated threshold; primary positive test.

Common random numbers pair the regimes within each world. This improves the
dose-response comparison without treating the four rows as independent.

## Outputs

The complete ledger records proposal noise and estimate, adoption, project
success, gross descendant gain, realized safe-oracle and learned-policy values,
structural checks, and a SHA-256 record hash. The summary reports theoretical
and realized values, normal mean intervals, medians, adoption rates, Wilson
intervals, and registered gate dispositions.
