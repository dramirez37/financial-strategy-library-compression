\section{Reproducibility Records}
\label{sec:supp-reproducibility}

This section records the execution boundaries, configuration histories,
hashes, and complete artifact locations for Supplements~S4--S6.  The commands
are reproduction instructions only; compiling this supplement does not run
Julia or regenerate any committed result.  The public repository is available
at
\begin{center}
\url{https://github.com/dramirez37/financial-strategy-library-compression}.
\end{center}

\subsection{Canonical and presentation records}

The canonical solve is deterministic and uses no random seed:
\begin{verbatim}
julia --project=julia \
  julia/scripts/solve_unified_canonical_benchmark.jl
\end{verbatim}
The manuscript presentation layer is Julia-generated:
\begin{verbatim}
julia --project=julia \
  julia/scripts/generate_manuscript_numerical_artifacts.jl
julia --project=julia \
  julia/scripts/generate_manuscript_numerical_artifacts.jl --check
\end{verbatim}
The first command validates the committed convergence, compression,
decomposition, geometry, grammar, mechanism, and uncertainty tables before
writing manuscript artifacts.  The second is nonmutating and rejects byte
drift.  Complete canonical numerical outputs are listed in Supplement~S4.
