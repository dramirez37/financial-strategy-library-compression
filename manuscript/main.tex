\begin{abstract}
Growing financial strategy libraries consume storage, validation, maintenance,
monitoring, and governance resources. Yet a retained strategy can be both an
operating asset, contributing to current payoff, and a generative asset,
carrying modules needed to produce future descendants. We study a finite
partial-information process whose raw library dynamics project onto a
sufficient productive state comprising the operating frontier and the
generative closure. This reduction defines exact, source-relative compression
as the
minimum-resource sublibrary preserving both objects, and therefore productive
value and available optimal actions. Rechecking frontier and closure after
every deletion certifies a safe stepwise path, but an irreducible endpoint need
not be globally resource-minimal. The distinction is economically sharp: a
deletion that preserves every current payoff can eliminate the complete
attainable delayed descendant margin in the sharp bridge construction. Beyond
exact preservation, selection under a hard capacity or resource penalty
operates over finitely many library value--burden points. Capacity value is
stepwise and
can have increasing unit increments, while penalized value forms a convex
piecewise-affine envelope with discrete changes in the selected library. Exact
finite fixtures, registered synthetic stress tests, and retrospective
financial audits examine these mechanisms. The audits use held-out descendant
quality only after compression and support no causal, forecasting, alpha, or
deployable performance claim.
\end{abstract}

\section*{Data and Code Availability}
The project repository provides the formal and computational source code
together with the synthetic and exact experiment materials.  It is available
at
\begin{center}
\url{https://github.com/dramirez37/financial-strategy-library-compression}
\end{center}
The financial audits use licensed CRSP/WRDS source data; raw and row-level
licensed data cannot be redistributed.  Users with independent licensed access
can reproduce the licensed-data portions using the supplied procedures.
Online Supplement~S7 provides reproducibility commands and artifact records.
