# Exact Fixtures

This directory contains eighteen version-2 records generated by
`julia/scripts/export_exact_fixtures.jl`. Thirteen cover the requested unified
claim-boundary fixtures:

- raw-to-compressed transition identity;
- raw/compressed value equality;
- safe deletion;
- normalized pruning loss;
- operational–generative decomposition;
- a generative lower bound;
- discount–survival complementarity;
- persistence-increases-coverage and persistence-decreases-coverage examples;
- frontier–closure substitution and complementarity;
- a monotone-gap threshold; and
- multi-gap disconnection.

Five migrated compatibility records preserve the previously committed
current-zero/future-positive, arbitrary frontier-pruning, finite Strategy
Innovation Equation, destructive-kernel single-gap, and disconnected-region
multi-gap examples.

Files are ordered lexicographically by fixture ID and their arrays preserve
declared catalog order. Rational values use reduced `numerator//denominator`
strings. Unified projects carry strictly positive `duration`; the version-2
contract has no zero-delay project field. Do not edit these JSON records or
the paired generated Lean module by hand. Regenerate them from the repository
root with:

```sh
julia --project=julia julia/scripts/export_exact_fixtures.jl
```

Use `--check` for a non-mutating local drift gate. CI regenerates the artifacts
and fails if `git diff` detects a change.

Fixture agreement validates exact implementation correspondence on these
selected finite examples. It does not replace, prove, or change the status of
the corresponding general Lean theorems.
