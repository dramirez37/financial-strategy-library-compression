# Online Resource 1: source assignments

This directory holds journal-facing material removed from the main exposition
while the main article is rewritten. It is not yet the final standalone Online
Resource build.

- 01_probability_normalization.tex contains the exact probability-table,
  admission-normalization, marginal, and pushforward identities supporting the
  projection theorem.
- 03_secondary_comparative_statics.tex contains the retained secondary
  sensitivity results, including elasticity, duration, and switching
  conventions. The complete belief-occupation, threshold, persistence, and
  frontier--closure interaction sources remain assigned here by the migration
  map. None is used to establish the tagged-cover, complexity, preprocessing,
  or algorithmic claims.
- Complete tagged-cover boundary examples, the complexity reduction audit,
  preprocessing proofs and reconstruction maps, DP reconstruction proof,
  algorithm certificates, and finite gap fixtures remain in their existing
  journal source modules and reports until the Online Resource is assembled.
- Complete v2 exact-agreement rows, scaling and semantic-check tables,
  performance-profile and diagnostic figures, registered model coefficients,
  failed-run census, and exploratory reference-attainment regression remain in
  `journal/aor/tables/`, `journal/aor/figures/`, and the audited v2 report. The
  main article uses only compact Julia-generated inputs.
- Complete terminal and annual information sets, aggregate identity-overlap
  rows, tied ranks, empty-residual certificates, postdecision diagnostic
  formulas, and reproduction contracts remain in the financial reports and
  public-safe aggregate tables. Terminal and annual diagnostic units are never
  pooled, and licensed source rows are excluded.

The main article uses textual references such as “Online Resource 1,
Section S1” rather than unresolved external LaTeX labels. No theorem is
instantiated a second time in the main article.
