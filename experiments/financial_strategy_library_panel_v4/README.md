# Financial strategy library panel v4

V4 is a Julia-first, calibrated mechanism experiment. It asks whether the
positive AOR bridge-margin theorem is recovered when a financial descendant is
available only through a capability retained by innovation-safe compression.

The experiment deliberately separates two questions:

1. **Mechanism value:** under a registered closure-active data-generating
   process, does the safe library retain the positive option value that the
   burden-matched frontier-only library cannot access?
2. **Statistical exercise:** can a frozen learner adopt in the powered positive
   regime while controlling adoption in null and adversarial regimes?

V3 remains sealed and unchanged. Its licensed proposal paths enter only through
aggregate estimates of daily residual volatility, serial dependence, and tail
thickness. No security identifiers or return observations are exported to v4.

## Reproduction

```sh
make aor-financial-panel-v4-calibration-check
make aor-financial-panel-v4-design-check
make aor-financial-panel-v4-tests
make aor-financial-panel-v4-run
make aor-financial-panel-v4-result-audit
```

The design lock must exist and validate before the runner can create a world
ledger. The result audit recomputes every registered summary and verifies every
per-world record hash before accepting the result seal.
