# Springer Nature template provenance

The journal wrapper vendors two unmodified files from the official Springer
Nature journal-article LaTeX template package, version 3.1 (December 2024):

- `sn-jnl.cls`
- `bst/sn-mathphys-ay.bst`

Official source:
<https://www.springernature.com/gp/authors/campaigns/latex-author-support>

Downloaded from the package linked by that page on 2026-08-26. The complete
downloaded ZIP had SHA-256
`812e76dcaa9c28dc1bff1fb6065d51729b67d4ea140552a05088317414a3ecae`.
The class and bibliography style hashes are enforced by `journal/aor/check.sh`.
