\section{Registered Algorithmic Compression Benchmark v2}
\label{sec:or-algorithmic-benchmark-v2}

\begin{center}
\fbox{\parbox{0.93\linewidth}{\textbf{New journal-program evidence.}
This prospectively registered algorithmic benchmark is distinct from the
frozen preprint-era \(N=1024\) randomized study in Section~S11. No seed,
registry row, design lock, or result is shared or relabeled across the two
programs.}}
\end{center}

The locked v2 analysis population contains (AORBenchmarkInstances) instances:
(AORBenchmarkSmallExact) small exact, (AORBenchmarkStructured) structured,
and (AORBenchmarkAdversarial) adversarial. Its
(AORBenchmarkRuns) registered run units retain every terminal outcome;
(AORBenchmarkAccepted) returned libraries passed independent exact checks
and (AORBenchmarkUnsuccessful) records returned no accepted library. These
counts are generated from the committed audit summary through
\path{tables/evidence_macros.tex}.

The design, analysis plan, reporting rules, seed and instance registries,
amendments, active design lock, execution-start lock, environment record, raw
run matrix, and independent audit are under
\path{experiments/algorithmic_compression_v2/}. The final runner used
(AORWorkerCount) concurrent one-thread subprocesses. Runtime is therefore an
eight-worker contention estimand on an (AORCPU), not a claim about serial
algorithm complexity or another machine.
